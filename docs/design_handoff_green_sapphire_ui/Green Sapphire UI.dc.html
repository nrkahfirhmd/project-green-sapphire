GREEN SAPPHIRE · UI DESIGN · v1
INTERFACE SYSTEM
Direction: echo the ASCII world. Every element is drawn the way a terminal would draw it: one monospace face (IBM Plex Mono, 400 and 600), square-cornered frames with 2-unit strokes and solid 8-unit corner ticks standing in for box-drawing characters, and diamonds built from rotated squares. The world fills its 6 × 7 grid with glyphs; the UI uses the same rhythm but stays crisp, so it reads as the frame around the world rather than part of it. Pale Jade is rationed to five uses only: boss health, the low-HP pulse, a hit flash, a dropped sapphire, and the gate opening. Everything else, including focus, selection, pressed states and the title, uses Sapphire Core at a full or reduced alpha, plus inversion (a Core fill with Deep Moss text). So the brightest colour on screen always means "look now".

SPEC SHEET
Units are canvas units at 1950 × 900. "Safe TL" means the top-left corner of the safe area (135, 0); "Safe BR" is (1815, 852). x offsets go inward from the named edge, y offsets go down from the top or up from the bottom. On a 16:9 canvas (1950 × 1097) top-anchored items keep their y and bottom-anchored items move with the bottom edge. Centred items use the safe-area centre x = 975. Corner radius is 0 everywhere except circles.
